# لندینگ پیج دوره‌های آموزشی شهرک علمی و تحقیقاتی اصفهان

این صفحه کاملاً **آفلاین** و **self-hosted** است؛ هیچ وابستگی خارجی به CDN یا اینترنت ندارد.

## ساختار پوشه‌ها

```
landing/
├── index.html                  ← فایل اصلی صفحه
├── README.md                   ← همین فایل
└── assets/
    ├── css/
    │   ├── fonts.css           ← تعریف @font-face فونت وزیرمتن
    │   ├── tailwind.css        ← Tailwind بیلدشده (فقط کلاس‌های استفاده‌شده، حدود ۹ کیلوبایت)
    │   └── styles.css          ← استایل‌های سفارشی (کارت‌ها، پوستر، ویدئو و ...)
    ├── fonts/                  ← فایل‌های فونت Vazirmatn با فرمت woff2
    │   ├── Vazirmatn-Light.woff2
    │   ├── Vazirmatn-Regular.woff2
    │   ├── Vazirmatn-Medium.woff2
    │   ├── Vazirmatn-Bold.woff2
    │   ├── Vazirmatn-ExtraBold.woff2
    │   └── Vazirmatn-Black.woff2
    ├── js/
    │   └── main.js             ← اسکریپت fade-in، ناوبری، و جایگزینی خودکار ویدئو
    ├── posters/                ← پوسترهای دوره‌ها (jpg)
    │   ├── course-1.jpg        ← دوره اول (آبی - تهران)
    │   ├── course-2.jpg        ← دوره دوم (سبز - اصفهان)
    │   ├── course-3.jpg        ← دوره سوم (placeholder - نیاز به پوستر واقعی)
    │   ├── course-4.jpg        ← دوره چهارم (نارنجی - یزد)
    │   ├── course-5.jpg        ← دوره پنجم (placeholder - نیاز به پوستر واقعی)
    │   └── course-6.jpg        ← دوره ششم (placeholder - نیاز به پوستر واقعی)
    └── videos/                 ← محل قرارگیری ویدئوهای دوره‌ها
```

## نکته درباره فونت

چون فونت IRAN Yekan استاندارد اصفهان مجوز آزاد برای توزیع عمومی ندارد و قابلیت دانلود مستقیم در این محیط نبود، از فونت **Vazirmatn** استفاده شده — فونت فارسی با کیفیت بالا، مجوز OFL و طراحی مشابه Yekan.

اگر فایل‌های فونت IRAN Yekan را در اختیار دارید، کافی است:
۱. فایل‌های `woff2` را در پوشه `assets/fonts/` جایگزین کنید (با نام‌های مشابه)
۲. یا مسیر src در `assets/css/fonts.css` را ویرایش کنید

## اضافه کردن ویدئوهای دوره

صفحه به‌صورت هوشمند طراحی شده:
۱. هر ویدئو را به پوشه `assets/videos/` با نام زیر کپی کنید:
   - `course-1.mp4`
   - `course-2.mp4`
   - `course-3.mp4`
   - `course-4.mp4`
   - `course-5.mp4`
   - `course-6.mp4`
۲. صفحه را رفرش کنید — اسکریپت `main.js` به‌صورت خودکار تشخیص می‌دهد که فایل موجود است و placeholder را با پلیر ویدئوی واقعی جایگزین می‌کند
۳. اگر فایلی وجود نداشته باشد، placeholder نمایش داده می‌شود

**فرمت پیشنهادی ویدئو:** عمودی (۹:۱۶)، MP4 با کدک H.264

## جایگزینی پوسترها

پوسترهای دوره‌های ۳، ۵ و ۶ در حال حاضر placeholder هستند. کافی است فایل‌های با نام‌های `course-3.jpg`، `course-5.jpg` و `course-6.jpg` را در `assets/posters/` جایگزین کنید.

## اجرای لوکال برای تست

چون فایل `main.js` از `fetch()` برای تشخیص ویدئو استفاده می‌کند، باید صفحه از طریق یک وب‌سرور باز شود (نه با باز کردن مستقیم فایل):

**با Python:**
```bash
cd landing
python3 -m http.server 8080
# سپس مرورگر را باز کنید: http://localhost:8080
```

**با Node.js:**
```bash
cd landing
npx serve -p 8080
```

## ویرایش محتوا

تمام محتوای متنی داخل `index.html` قرار دارد و به راحتی قابل ویرایش است. هر دوره در یک `<section>` با id مشخص قرار دارد:
- `#course-1` تا `#course-6` برای دوره‌ها
- `#hero` برای سکشن معرفی
- `#contact` برای سکشن تماس

## رنگ اختصاصی هر دوره

هر سکشن دوره یک کلاس `accent-N` دارد که رنگ لهجه‌ی آن را تعیین می‌کند. تغییر رنگ در فایل `styles.css` قابل انجام است:
- `accent-1` → آبی
- `accent-2` → سبز تیل
- `accent-3` → بنفش
- `accent-4` → نارنجی
- `accent-5` → صورتی
- `accent-6` → صورتی (قابل تغییر)
